# Kang Min Su - Portfolio

[포트폴리오 열기](https://uxnim.github.io/portfolio/)

이 저장소에는 GitHub Pages에서 제공하는 정적 웹 파일만 있습니다.

| 경로 | 용도 |
| --- | --- |
| `index.html` | 메인 페이지 |
| `projects/` | 프로젝트와 연구 경험 상세 페이지 |
| `experience/` | 현장실습 상세 페이지 |
| `media/` | 공개 승인된 이미지 |
| `fonts/` | 자체 호스팅 웹폰트와 라이선스 |
| `site.css`, `client.js` | 공통 스타일과 인터랙션 |
| `.nojekyll` | GitHub Pages 정적 파일 제공 설정 |

자료 원본, 증명서, 개인 경력 문서, 소스코드, 로컬 검토 자료는 이 저장소에 포함하지 않습니다. HTML과 자산 경로는 상대 경로로 연결되며 각 상세 페이지에 직접 접근할 수 있습니다.

화면은 별도 개발 작업 폴더에서 생성합니다. 이 저장소의 HTML·CSS·이미지를 직접 수정하면 다음 빌드와 내용이 달라질 수 있으므로, 변경은 소스에 반영한 뒤 검증된 정적 파일로 갱신합니다.
