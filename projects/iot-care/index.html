독거노인 생활 모니터링

센서 데이터를 서버에서 모아 이상 징후를 판단하고 알리는 시스템

PERIOD
2025
ROLE
서버 데이터 수집·이상 판단·알림 흐름
TECHNOLOGIES
Arduino · Python · ROS2 Humble · Ubuntu
개요문제와 제약구조기술적 결정검증과 결과한계와 배운 점
OVERVIEW

네 종류의 데이터로 생활 환경을 살핍니다

충격·온습도·연기·영상 네 종류의 데이터를 수집해 독거노인의 생활 환경에서 이상 징후를 판단하는 한이음 프로젝트입니다. 서버에서 이상 이벤트를 감지하면 알림 흐름으로 연결합니다.

MY SCOPE / TEAM CONTEXT

저는 서버에서 센서 데이터를 수집하는 구조를 설계하고, 수신한 데이터의 이상 징후를 판단하는 로직과 알림 흐름을 맡았습니다. 센서 장치에서 들어온 데이터가 서버 판단과 알림으로 이어지도록 연결했습니다.

PROBLEM & CONSTRAINTS

문제와 제약

  1. 서로 다른 형태의 데이터를 센서별로 받아야 했습니다.
  2. 서버가 수신한 데이터를 판단에 사용하고, 이상 이벤트가 발생하면 알림으로 넘겨야 했습니다.

ENGINEERING DECISIONS

서버에서 이상 징후를 판단하고 알림으로 연결했습니다

Server-side monitoring

서버에서 수집·판단·알림 연결

문제

충격·온습도·연기·영상 데이터는 형태가 서로 달랐고, 이상 징후를 판단한 뒤 알림으로 연결해야 했습니다.

선택

서버에 센서별 수신 구조를 두고 수신·판단·알림 단계를 구분했습니다.

구현

센서별 데이터 수집 구조와 이상 판단 로직을 구현하고, 이상 이벤트가 발생하면 알림 흐름으로 넘어가도록 서버와 장치를 연결했습니다.

이유

어떤 데이터가 들어왔는지와 서버가 어떤 이벤트를 판단했는지를 단계별로 확인할 수 있어야 했습니다.

결과

네 종류의 센서 데이터가 서버에 들어와 이상 판단과 알림 흐름으로 이어지는 구조를 프로젝트에 적용했습니다.

범위와 한계

실제 돌봄 환경에서의 효과와 긴급기관 연계는 별도 검증이 필요합니다.
